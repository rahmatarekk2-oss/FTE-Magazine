# BS Fintech and Entrepreneurship: Program Magazine

KFUPM Business School · April 2026

A page-turning magazine version of the BS Fintech and Entrepreneurship degree plan.
Swipe, drag, click or use the ← → keys to turn pages.

## Publish on GitHub Pages

1. Create a new public repository, for example `fte-magazine`.
2. Click **Add file → Upload files** and drag in **every file in this folder** (index.html and all the images). They all sit side by side; there are no subfolders.
3. Click **Commit changes**.
4. Open **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
5. After a minute or two the magazine is live at `https://<your-username>.github.io/<repository-name>/`.
